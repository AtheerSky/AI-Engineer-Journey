# Solar Energy & Air Quality Prediction

This project applies machine learning to predict daily solar energy output and next-day air quality using weather, air quality, and solar panel data.

## What I learned

- Data preprocessing and feature engineering.
- Building regression and classification models.
- Comparing different machine learning algorithms.
- Evaluating models using appropriate metrics.
- Explaining predictions with SHAP.
- Working with live APIs (Open-Meteo).
- Building a simple Retrieval-Augmented Generation (RAG) pipeline for evidence-based recommendations.
